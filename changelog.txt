Version: 1.2.0
Date: ????
  Optimisations:
    - Roughly halved the work the readers do each update. On a 200-station network the refresh
      dropped from 12.1ms to 6.9ms, and each combinator update from 66us to 21us.
    - The mod no longer copies Cybersyn's entire station table every update just to find out which
      stations exist. It tracks that from Cybersyn's station created/removed events and reads only
      the handful of fields it actually uses.
    - Item signals are no longer taken apart and re-validated once per combinator per update.
  Changes:
    - Requires Cybersyn's interop events (station created/removed). No configuration needed; the
      station list is rebuilt automatically on load and whenever mods change.
  Bugfixes:
    - The network selector now spans the whole window instead of stopping partway across it, and
      the empty strip below it is gone. Both appeared once the signal grid grew wide enough to
      set the window width.

Version: 1.1.0
Date: 2026-07-31
  Features:
    - Updated to Factorio 2.1. Now requires Factorio 2.1.7, flib 0.17.1 and Cybersyn 2.1.2.
  Bugfixes:
    - Existing readers that never updated are now picked up automatically instead of having to be rebuilt
    - Readers placed on space platforms, or by scripts, blueprints and cloning, now work
    - Fixed a crash when mining a reader after another reader was destroyed without an event
    - Fixed a reader outputting nothing when its first logistic section was disabled
    - Fixed a crash when Cybersyn holds a station whose combinator was destroyed
  Changes:
    - Requester and delivery readers now use their high resolution sprites and cast a correct shadow, thanks to UltraJohn
    - Build and mine events are now filtered instead of firing for every entity placed
